# Protótipo comercial — senhor-pizza

**Demonstração preparada pela KnowHowTech. Não é o site oficial da empresa.**

Este repositório contém apenas o export estático de um protótipo de site, criado como material
de prospecção comercial. Fotos, logo e textos são conteúdo público do Instagram da própria empresa,
usados exclusivamente para demonstração ao seu proprietário. Caso a empresa não contrate o serviço,
o protótipo é removido. Todas as páginas levam obots: noindex, nofollow.

Publicado em: https://Abilioreinaldo.github.io/prototipo-senhor-pizza/
